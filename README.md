# 点点餐 · 西安理工大学预点餐系统（曲江校区）

基于微信小程序云开发的高校食堂预点餐平台，为西安理工大学曲江校区师生提供便捷的线上点餐、订单管理和食堂导航服务。

## 功能特性

### 🏠 首页
- **智能问候** — 根据时段显示个性化欢迎语
- **滚动公告** — 平台通知与活动信息轮播
- **轮播广告** — 促销活动与推荐内容展示
- **食堂导航** — 六大食堂快捷入口（第一~第五食堂 + 民族食堂）
- **推荐菜品** — 精选菜品与排行榜展示
- **全局搜索** — 支持菜品名称与店铺搜索（300ms 防抖）

### 🛒 点餐与购物车
- **菜单浏览** — 按食堂/档口分类浏览菜品
- **菜品详情** — 展示菜品信息、价格、用户评价
- **购物车** — 按用户 + 食堂隔离购物车数据（本地存储）
- **直接购买** — 从详情页一键快速下单

### 📋 订单管理
- **下单结算** — 按档口分组、选择取餐时间、添加备注、确认支付
- **订单状态** — 待支付 → 制作中 → 待取餐 → 待评价 → 已完成
- **取餐码** — 下单自动生成 5 位随机取餐码
- **订单操作** — 催单、取消订单、退款、确认取餐、再来一单
- **订单搜索** — 按订单号、手机号、菜品名、档口、备注等多维度搜索（400ms 防抖）

### ⭐ 评价系统
- **星级评分** — 1~5 星打分
- **快捷标签** — 快速选择评价标签
- **图片上传** — 最多 9 张评价图片（云存储）
- **匿名评价** — 支持匿名发布

### 👤 个人中心
- **用户认证** — 手机号注册/登录，SHA-256 密码加密
- **双重登录** — 学生用户 + 厨师/员工双账号体系
- **密码找回** — 密保问题两步验证
- **自动登录** — 本地会话持久化

### ❤️ 收藏与优惠券
- **菜品收藏** — 添加/取消/查看收藏菜品
- **领券中心** — 浏览可用优惠券并领取
- **我的优惠券** — 查看有效/已过期优惠券

### 🎲 趣味功能
- **随机食堂** — "今天吃什么？"滚动随机选餐，支持震动反馈和历史记录

### 👨‍🍳 厨师端
- **厨师看板** — 厨师/员工专用管理入口

| 框架 | 微信小程序原生（WXML + WXSS + JavaScript） |
| 组件框架 | glass-easel |
| 后端 | 微信云开发（Cloud Base） |

| 集合 | 用途 |
|------|------|

| `evaluate` | 菜品评价数据（评分、内容、图片、匿名标识） |

### 云存储路径

- `wx_Cover/` — 用户头像上传
- `wx_feedback/` — 评价图片上传

## 环境配置

本仓库不含任何真实密钥，以下两项需要本地配置（均已被 `.gitignore` 排除，不会被提交）：

| 配置项 | 本地文件 | 说明 |
|--------|----------|------|
| 云环境 ID | `config/env.local.js` | 小程序运行时通过 `config/env.js` 读取 |
| AppID | `project.private.config.json` | 开发者工具个人私有配置，优先级高于 `project.config.json` |

**首次运行步骤：**

1. 复制 `config/env.local.example.js` 为 `config/env.local.js`，填入你的云开发环境 ID
   （位置：微信开发者工具 → 云开发控制台 → 环境 ID）
2. `project.config.json` 中默认使用占位 AppID `touristappid`，导入项目后在开发者工具中填入你自己的 AppID（会自动写入 `project.private.config.json`）
3. 在云开发控制台创建上表中的全部集合，并建议将权限设置为「仅创建者可读写」或自定义安全规则

> ⚠️ 请勿将真实 `env.local.js` 或含 AppID 的私有配置提交到仓库。

## 本地开发

1. **克隆项目**

   ```bash
   git clone https://github.com/HermitWJ/diandiancan.git
   ```

2. **导入项目**
   - 打开微信开发者工具
   - 选择「导入项目」，指向项目目录
   - 填入你自己的 AppID

3. **完成环境配置**
   - 按上文「环境配置」一节创建 `config/env.local.js` 并填入云环境 ID
   - 开通云开发并创建全部集合

4. **启动编译**
   - 点击「编译」即可预览

## 使用流程

1. **注册/登录** — 使用手机号注册账号，设置密保问题
2. **浏览点餐** — 进入食堂选择菜品，加入购物车
3. **下单支付** — 确认订单、选择取餐时间、提交
4. **取餐就餐** — 凭取餐码到对应档口取餐
5. **评价反馈** — 对已取餐订单进行评分和评价

## 环境要求

- 微信开发者工具 ≥ 最新稳定版
- 微信 App 基础库 ≥ 2.0.0
- 需开通微信云开发（Cloud Base）
